Datadog

Software Engineer · Bits Investigation

Current

Bits Investigation is Datadog's AI SRE: an agent that picks up a production alert, digs through metrics, logs, and traces, and explains the root cause. I work on making it dependable enough to run on real production incidents.

Getting Scout ready for production

Datadog recently announced Scout 1.0, its first in-house model built for investigating production issues. Scout was trained with reinforcement learning in simulated incident environments. My role was getting the model into production: wiring it into Bits Investigation so we could measure it on our actual production datasets instead of only the training environment it learned in.

Closing that gap between simulation and the real world matters. A model that scores well in its own training environment still has to hold up on real alerts, real telemetry, and the tools Bits actually calls in production.

Pipelines that survive anything

At this scale, something is always broken somewhere. I worked on making the pipelines resilient to the three ways things fail:

  • Configuration: bad pushes and misconfigurations shouldn't take processing down.
  • Data: malformed, unexpected, or skewed input shouldn't stop the pipeline.
  • Infrastructure: machine, network, and datacenter failures should slow processing down, not stop it.

From a day to a few hours

My work brought average end-to-end latency down from about 24 hours to 6 hours, so teams that depended on these logs got their data roughly four times sooner.
